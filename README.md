# Blood Donor Finder

Blood Donor Finder is a modern web application designed to seamlessly connect blood donors with individuals and hospitals in need of life-saving blood donations. 

## Features

- **Donor Registration:** Easy sign-up process for individuals willing to donate blood.
- **Find a Donor:** Search functionality to quickly find compatible blood donors in your area.
- **Hospital Signup:** Dedicated registration and interface for hospitals to request and manage blood supplies.
- **User Dashboard:** Personalized dashboard for users to manage their profiles, history, and requests.
- **Admin Panel:** Centralized administration interface to manage users, hospitals, and platform activity.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** Radix UI

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JayPatel-c/BloodDonorFinder.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or yarn install, pnpm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   # or yarn dev, pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
